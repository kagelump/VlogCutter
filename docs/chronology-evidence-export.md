# Chronology evidence export

`vlogcutter chronology evidence --project PROJECT_ID [--offset 0] [--limit 100] [--facts-revision TOKEN]` emits a bounded JSON page from the local catalog. The limit is 1–500. Each response includes a `factsRevision`, non-asset chronology context, stable asset ids, capture sequence/counter membership, timestamp candidate observations, solved rows (including applied evidence), contradictions, and `nextOffset`.

Pass the first page's `factsRevision` on every subsequent request. If any chronology fact changed, the command returns `chronology.facts_changed`; restart from offset zero and use the new token. Reads use the stored catalog only and do not probe media. New probes store each format/stream `creation_time` observation and a compact filename timestamp observation, including exact origin, original text, parsed value, timezone claim, parse status, and any known semantics. Filename timestamps remain timezone-free wall-clock observations with unknown start/end meaning unless a source explicitly supplies that meaning. Legacy assets return `timestampCandidates: null` to state that candidate provenance was not retained; a new probe that found none returns an empty array.

`candidateComparisons` summarizes observable disagreements. Wall-clock values without an explicit timezone are never compared as UTC instants. Start/end duration comparisons are included only when both stored candidates explicitly carry those semantics and both parse to timezone-aware instants; `durationDeltaSeconds` is the observed interval minus clip duration, and `durationExplainsDifference` says whether it is within one second. Explanations keep camera-clock evidence, display timezone, and physical trip location separate; no observation applies a correction. Camera clock correction remains a separate explicit chronology operation.

Timestamp candidate records are stored with the immutable project asset operation and included in portable baselines, so offline replicas retain the evidence. Filesystem modification time is not substituted for camera timestamp evidence.
